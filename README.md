# Traffic Radar System

A simple Java OOP application that simulates a traffic radar system and generates traffic fines based on predefined traffic rules.

## Features

- Check vehicle speed based on vehicle type.
- Detect seatbelt violations.
- Generate a traffic fine report.
- Easily extend the system by adding new traffic rules.

  
## Technologies

- Java
- Object-Oriented Programming (OOP)

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Run `Main.java`.
